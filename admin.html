GitHub 연결

사이트 파일이 있는 저장소와 토큰을 연결하면, 이 화면에서 바로 사이트를 수정할 수 있습니다.

토큰 발급 방법 (처음 한 번만 하면 됩니다)
  1. github.com/settings/tokens → Generate new token 를 엽니다.
  2. Token name 에 아무 이름(예: hedon139-site-admin)을 적고, Expiration 은 90 days 정도로 정합니다.
  3. Repository access → Only select repositories → 사이트가 들어 있는 저장소를 고릅니다.
  4. Permissions → Repository permissions → Contents 를 Read and write 로 바꿉니다. (Metadata 는 자동으로 Read)
  5. Generate token 을 누르고 github_pat_... 로 시작하는 값을 복사합니다. 이 화면을 닫으면 다시 볼 수 없습니다.
  6. 위 입력란에 아이디·저장소·토큰을 넣고 설정 저장 → 연결 확인 을 누릅니다.
사이트를 인터넷에 공개하는 방법 (GitHub Pages)
  1. 저장소 → Settings → 왼쪽 메뉴 Pages 로 갑니다.
  2. Build and deployment → Source 를 Deploy from a branch 로, Branch 를 main / /(root) 로 지정하고 Save.
  3. 1~2분 뒤 https://아이디.github.io/저장소이름/ 주소로 사이트가 열립니다.
  4. 이 관리자 페이지는 https://아이디.github.io/저장소이름/admin.html 로 접속합니다.
연결이 안 될 때
  • 401 — 토큰이 틀렸거나 만료되었습니다. 새로 발급해 다시 넣어 주세요.
  • 403 / 404 — 저장소 이름·아이디가 다르거나, 토큰의 Contents 권한이 Read 로만 되어 있습니다. Read and write 로 바꿔 주세요.
  • 사이트를 연 주소와 관리자 주소가 같은지 확인하세요. (예: 아이디.github.io/저장소/admin.html)
